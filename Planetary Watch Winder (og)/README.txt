Gyro Watch Winder V2 by Mike20h on Thingiverse: https://www.thingiverse.com/thing:6074061

Summary:
This watch winder is a modified version of "Gyro Winder watch hoder" by ale2002 (https://www.thingiverse.com/ale2002/designs).  There was a ton of room for improvement.  I added slots for common bearings, cutouts for all the hardware you will need, and redesigned all the tolerances and clearings so she runs nice and smooth.  I also redid every single part in nice round numbers in the metric system.  All the electronics come from this guide by sime_dax (https://www.thingiverse.com/thing:2021221) and tutorials for all the wiring and copy-paste-able code can be found here:
